## 📖 About the Project

**Touch Grass** is a web application designed to encourage users to reduce unnecessary screen time, take mindful breaks, and reconnect with the real world.

Built using HTML, CSS, and JavaScript, the project promotes digital well-being through offline activity ideas and interactive features.

The project can also be extended with open-source AI to suggest personalized activities based on user preferences.

## 🎯 Problem Statement

Excessive screen time and continuous social media usage can make it difficult to maintain a healthy balance between online and offline activities.

Many people want to spend less time on their phones but do not know what to do instead.

Touch Grass aims to make digital detoxing simple, enjoyable, and accessible.

## 💡 Our Solution

Touch Grass encourages users to:

- Take breaks from digital devices.
- Discover fun offline activities.
- Spend more time outdoors.
- Develop healthier digital habits.
- Explore AI-powered activity suggestions as the project develops.

## 🤖 Open-Source AI

A future version of Touch Grass can use an open-weight AI model to recommend offline activities according to:

- Available time
- Personal interests
- Indoor or outdoor preferences
- Preferred activity types

Tools such as [Ollama](https://ollama.com/) can help developers experiment with compatible models locally.

### Why Open Innovation Matters

- **Transparency:** Developers can inspect and understand the tools they use.
- **Flexibility:** Different models can be explored and customized.
- **Accessibility:** Developers can learn and experiment with AI technologies.
- **Community:** Contributors can collaborate and improve the project.
- **Local AI:** Compatible models can run locally, depending on hardware requirements.

Check the model's license before using or redistributing it. Never expose private API keys in public JavaScript files.
